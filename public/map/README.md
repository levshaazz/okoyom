# Test Coast — вымышленный тестовый регион (без лора)

Кусок умеренного побережья ~40 × 22.5 км для отладки 3D-карты. Имена служебные (Test Harbor и т. п.). Это не география кампании.

| файл | что |
|---|---|
| albedo.jpg | 4096×2304, вид строго сверху, без подписей |
| height16.png | uint16, m = −80 + v/65535·880 (уровень моря 0 м) |
| water.png | 8-бит маска воды (море + озеро + река). У пляжа мелководье местами не попало в маску |
| forest.png | 8-бит маска леса (белое — лес). Слой «Леса»: тёмный зелёный полог, небольшой подъём и редкие кроны |
| ../../src/data/test-coast.json | размеры, шкала высот, 6 мест, тестовые дороги |

Страница читает этот набор через `src/data/map-manifest.ts`. Вертикальное преувеличение на сайте ×4 (в файле предложен диапазон ×1.5–3): при ×10 хребет становится иглами. Сетка высот слегка размыта, нормали считаются по более широкому шагу. Вода — и по маске, и везде, где высота ниже 0 м.

Лес на Test Coast — маска `files.forest`. Отдельного файла дорог нет: линии лежат в `roads` и помечены TEST. Это не лор.

Настоящий материк подключается теми же полями.

`roads` — массив. Каждая линия:

| поле | |
|---|---|
| `id` | строка |
| `tier` | `tract` (шире и светлее), `road`, `trail` (тонкий пунктир), `sail` (точки над водой) |
| `points` | ломаная `{x, y}` в долях 0…1, левый верхний угол, север сверху |
| `name` | необязательное имя |
| `label` | необязательная подпись на карте |
| `assumed` | необязательно: ход предположительный, рисуется реже и бледнее |

`files.roads` — необязательная PNG-маска осевых линий (её нет в тестовом крае). Значение красного или серого канала:

| значение | ярус |
|---|---|
| 255 | tract |
| 170 | road |
| 110 | sail |
| 85 | trail |

Остальные значения — не дорога. Маска переводится в те же ленты, что и массив. Если заданы оба, рисуются оба. Слой в интерфейсе — «Дороги». Кроны редеют с расстоянием и на телефоне; полог остаётся.
